# Player Commands

Type commands with a leading **[** (for example `[compendium`). Say **[commands** in game to see the list the staff currently has turned on.

## Info & help

| Command | What it does |
|---|---|
| `[help` | New player help menu |
| `[rules` / `[chatRules` | Server rules / chat rules |
| `[wiki` | Opens the wiki browser |
| `[compendium` | Opens the [Compendium](compendium.md) |
| `[patch` | Latest patch notes |
| `[time` | Server time |
| `[captcha` | Opens the captcha window if one is required |
| `[getHue` | Target an item to see its hue number |
| `[commands` | The command list |

## Spoken commands

Say these out loud:

| Phrase | What it does |
|---|---|
| *bank* | Opens your bank near a banker or vendor |
| *stable* / *claim* | Stable or claim pets near an animal trainer |
| *vendor buy* / *vendor sell* | Trade with a nearby vendor |
| *i wish to place a trash barrel* | Places a house trash barrel |
| *i ban thee* / *remove thyself* | Ban / kick someone from your house |
| *i wish to lock this* / *i wish to secure this* / *i wish to release this* | Lock down, secure or release a house item |
| *i wish to duel* | Challenge a nearby player to a [duel](dueling.md) |
| *i seek revival* | Points you to the nearest healer |
| *send me home* | Sends your ghost to your home city |
| *i seek my enemies* | Militia: senses nearby enemies |
| *i seek justice* / *i seek murderers* | Paladins: senses nearby murderers |
