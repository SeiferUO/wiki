# Global Chat

The Global Chat lets you talk to everyone online, wherever they are. It has four channels:

| Channel | Command | Who sees it |
|---|---|---|
| **General** | `[C <message>` | Everyone |
| **PvP** | `[P <message>` | Everyone |
| **Trading** | `[T <message>` | Everyone |
| **Guild** | `[G <message>` | Your guild only |

Say a channel command **without a message** to open the chat window on that channel.

## Chat window

- Say **[Chat** (or `[C` alone) to open it. It also opens at login.
- Each channel has its own **tab** with the last **50 messages**. Tabs with new messages are marked as unread.
- You can clear the history of one channel, or all of them.
- The General, PvP and Trading histories are cleared automatically every 10 hours.

## Rules

- After each message you must wait **5–10 seconds** before sending another.
- You need to be in a guild to use the Guild channel.
- **[ChatToggle** turns the chat off (or back on) for your whole account. While it's off you don't see or send chat messages.
- Staff can mute players, temporarily (30 minutes) or permanently. Read the chat rules with **[chatRules**.
