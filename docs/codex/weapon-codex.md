# Weapon Codex

Each weapon skill has its own **Codex**, a talent tree of combat procs and passives: **Swordsmanship, Macing, Fencing and Archery**.
Buy the codex books from **Selwyn the Archivist** (1,500 gold each).

## Rules for every codex

- **PvM only.** Procs only trigger against monsters. Codexes do nothing in PvP.
- You need a weapon of that skill in hand. Swords, axes and polearms use the Swordsmanship codex.
- **No followers.** Codexes switch off while you have pets or summons out.

### Points

- Killing monsters with that weapon type gives codex XP: **Fame / 100** per kill (min 10). The *XP Bonus* talent adds +5% per tier.
- XP for the n-th point: **800 × n + 2 × (n − 1)²**.
- Each talent's tiers cost 1 point more than the tier before.

### Limits

- **Ability slots:** you can have **2 active procs** on at once (+1 from the *Ability Slot* talent). Archery has one extra slot.
- **Codex point gate:** once you've spent **25%** of all possible points, every further upgrade also needs a **Codex Point**. You get those from a **Book of Lost Knowledge**.
- **Build cap:** you can spend at most **75%** of all possible points, so you can't learn everything.
- **Reset:** 100 gold per point spent.

### Talents every codex has

| Talent | Effect per tier |
|---|---|
| Damage Bonus | +2% base damage |
| Accuracy Bonus | +2% hit chance |
| Speed Bonus | +2% attack speed |
| Aggression | +2% attack speed, but +2% damage taken |
| Combat Rhythm | +2% attack speed per consecutive hit (max 5 stacks) |
| Cooldown Reduction | −5% proc cooldowns (Fencing −2.5%) |
| XP Bonus | +5% codex XP |
| Ability Slot | +1 active proc (one tier) |
